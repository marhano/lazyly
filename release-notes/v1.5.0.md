## New: Run tests from the GUI

- Register named test suites for a project (e.g. "Unit Test", "E2E Test") in its Local settings --
  each points at a test project on your machine.
- A new "Run Tests" button in the Projects tab's build history runs every configured suite for that
  build and streams the output live into the output panel, the same way a publish does.
- Each build tracks its own Passed/Failed/Not started result -- an older build never shows a newer
  one's result, or vice versa.
- Works for both modern test projects and classic .NET Framework test projects (NUnit/MSTest/xUnit
  via packages.config) -- the two need very different tooling under the hood, and PublishTool now
  detects and handles both correctly.
- A combined Excel report is generated after every run and downloadable from the build-history grid
  (with a desktop notification when it's saved) and from the Hosting site's Build Archive.

## New: Non-developers can run tests too

- With a dev server configured (remote mode), clicking "Run Tests" now runs on the dev server
  itself instead of requiring the project's source on your own machine -- consistent with how every
  other remote-mode action already works.
- Each build automatically carries its own compiled test suites along with it, so the dev server
  never needs git, a checkout, or source access of any kind.
- Requires redeploying PublishTool.Hosting. Once redeployed, a classic test project needs nothing
  extra installed on the server; an E2E/Playwright suite installs its own browsers automatically the
  first time it runs there.

## Other

- Build history actions (Deploy, Mark latest, Delete, Run Tests) are now compact icon buttons.
- CLI: `add-project --test-suite "Name=Path"` (repeatable) replaces the older `--unit-tests`/
  `--unit-test-project` options.

## Fixes

- Classic (.NET Framework) test projects using packages.config previously reported "no tests ran"
  with no clear cause when run through the CLI's `dotnet test` -- these now build and run correctly.
- Test result counts no longer count a skipped test as a failure.
