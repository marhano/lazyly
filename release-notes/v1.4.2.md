## Projects: multiple Event Log filters

- The "Source name or message text" field in a project's Event Logs settings is now a list --
  add as many Source names (or message substrings) as needed, and an entry matches if it matches
  *any* of them. Existing single-value projects keep working unchanged.
- The CLI's `--event-log-filter-value` is now repeatable, same as `--feature`/`--fix`/etc.

## Dev Server Relays: connection status

- Saved relays now show a live "Status" column (Online/Offline) -- each one is pinged in the
  background as soon as the list loads, instead of only showing status after clicking "Test".
