## Critical fix

- Fixed v1.2.1 and v1.2.2 failing to install/launch at all, showing "Install Partially
  Succeeded" followed by "Something Went Wrong: the application has failed to start because its
  side-by-side configuration is incorrect." A stray formatting mistake in the app's manifest file
  (not something visible in normal use) made Windows reject it outright. If you hit that error on
  an earlier version, this is the fix -- please reinstall using this version's Setup.exe.
