## New: Firewall tab

- Manage inbound Windows Firewall rules for IIS site ports, right from PublishTool -- locally or
  on the dev server.
- Add a rule with a single port or netsh-style ranges (e.g. `9001,9005-9008`).
- Edit an existing rule's label, ports, or protocol in place.
- Full audit trail (History button) -- every rule added, edited, or removed, who did it, and when.
- "Show all rules" toggle for visibility into every rule on the system, not just PublishTool's
  own (read-only for anything PublishTool didn't create).

## Projects

- `.csproj` path is now optional -- register a project purely to redeploy an existing build, or
  manage its Event Logs/IIS/firewall rules, without needing a local source checkout.

## Fixes

- The Remote IIS section's shared "host root path" field could be edited without clicking "Edit
  shared settings" first, unlike the rest of that shared section -- now properly locked behind it.
