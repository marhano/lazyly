## Fixes

- Fixed "Update check failed: ... 403 (rate limit exceeded)". GitHub caps unauthenticated
  requests at 60/hour per network, which a team sharing an office connection could exhaust --
  the app now checks at most once every 6 hours per machine (instead of on every single launch)
  and spreads out exactly when each machine checks so simultaneous launches don't all land at
  once.

## Help tab

- New "Check for updates" button, for checking on demand instead of waiting for the automatic
  background check -- tells you if you're already up to date, or if something went wrong.
