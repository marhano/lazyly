## Projects tab

- Redeploying an older build now lets you pick Local or Remote as the deploy target (same
  Deploy target / Deploy to selector as the Publish tab), instead of always guessing based on
  whichever mode you're currently in.
- The Deploy this version button is now hidden for projects that don't have IIS deployment
  enabled anywhere, instead of showing and then just warning you when clicked.
- Deploying now shows progress in the status bar and locks the build history grid while it's
  running, so it's obvious when a deploy is in flight.
- New Refresh button next to the project list, so you can pick up a project a teammate just
  added or reconfigured without switching to the Publish tab first.

## IIS tab

- New filter to show All sites, only Started, or only Stopped.
- New Deployed Version / Deployed At / Deployed By columns, plus a History button showing a
  site's full deployment history with search.
- Browse Site now opens the dev server's own address when managing IIS remotely, instead of
  always opening localhost.

## Fixes

- Refreshing projects on the Publish tab now also reloads the App Config panel and deploy
  target options for whichever project is currently selected, so a teammate's changes to it
  actually show up instead of silently staying stale.
- Fixed App Config edits sometimes not making it into a publish if Publish was clicked right
  after editing a value, without clicking away from the cell first.
